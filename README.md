<h2 # ¡Hola! Bienvenidos a mi espacio de desarrollo 🚀

Estudiante de programación apasionado por el desarrollo web y los videojuegos. Me dedico a construir aplicaciones web estructuradas, eficientes y seguras, logrando un equilibrio entre una lógica de software sólida y un apartado visual único.

---

### 🎯 Mis Pilares de Desarrollo
* **Legibilidad ante todo:** Priorizo el código limpio y mantenible. Fiel creyente de que el código legible siempre supera al código corto.
* **Privacidad y Control:** Desarrollo con un enfoque estricto en la confidencialidad y la propiedad intelectual de mi código fuente, priorizando la gestión limpia y segura de dependencias.
* **Lógica Estructurada:** Dedicado a dominar la arquitectura del software desde las bases para construir soluciones óptimas.

### 🛠️ Proyectos en Marcha
* **Front-end & Game Dev:** Creación de simuladores dinámicos y juegos de gestión en la web.

### 🎨 Estética e Inspiración
Me apasiona la identidad visual de los proyectos. Conecto fuertemente con el estilo **Lofi**, el pixel art y los entornos digitales que incorporan texturas orgánicas y paletas de colores cálidas.

### ⚙️ Stack Tecnológico
* **Frontend & Frameworks:** Vue.js / JavaScript / HTML5 / CSS3
* **Entorno & Control de Versiones:** VS Code / Git / GitHub
